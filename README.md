# 干支历法排盘工具

以 Taro + React + TypeScript 编写的传统历法排盘工具，界面与安卓版 1.0.31 保持一致：深紫星空底、金色标题、八宫格入口、宣纸面板。全部数据在本地计算，无需登录、不联网、不收集任何用户信息。

**在线体验：** <https://37ktadqegx5r7s7z36b.traesite.cn>（H5 版，手机/桌面浏览器均可打开）

> 源码可见（Source-Available）。**商业使用需获得书面授权**，详见 [LICENSE](LICENSE)。

## 功能

| 模块 | 内容 |
|---|---|
| 今日黄历 | 公历农历、干支纪年、节气节日、月相物候；今日锦囊（宜忌 / 吉时 / 方位 / 开运）；时辰五行、神煞方位、十二时辰吉凶与月历 |
| 单人排盘 | 四柱（十神、藏干、纳音、十二长生、空亡）、五行个数统计、大运干支表；紫微十二宫星曜、庙旺、四化、大限 |
| 姻缘 | 双人八字合参与婚俗文化对照 |
| 事业 / 学业 | 行业节奏、财路、学科与读书运等民俗文化整理 |
| 起名 | 按八字喜用五行配字，附音义与笔画参考 |
| 方位 | 八宅命卦、八方星名与居家布局参考 |
| 星座 | 四象五行、星座档案与今日黄历联动 |
| 词典 | 52 条传统名词释义（十神 / 神煞 / 星曜 / 宫位 / 概念），含每日一词 |
| 关于 | 功能说明、数据来源、隐私声明、内容声明 |

设计要点：

- 排盘同时支持公历 / 农历输入，按出生地经度与均时差校正真太阳时
- 首页为八宫格入口（今日黄历 / 单人排盘 / 姻缘 / 事业 / 学业 / 起名 / 方位 / 星座），无底部导航
- 主题为深紫星空底 + 鎏金扫描光标题 + 宣纸质感卡片
- 图标全部为内联 SVG data URI，不依赖外部图片资源

## 技术栈

- Taro 4.1.9（WeChat / H5 / 其他小程序可复用同一套代码）
- React 18 + TypeScript 5
- Sass
- [lunar-javascript](https://github.com/6tail/lunar-javascript) — 农历与干支换算
- [iztro](https://github.com/SylarLong/iztro) — 紫微斗数安星

## 目录结构

```
src/
├── app.config.ts          页面路由（11 页，无 tabBar）
├── app.scss               全局主题（深紫星空底 + 宣纸卡片）
├── components/            Card / PageHead / BirthForm / Fold
├── engine/                排盘引擎（纯函数，无 UI 依赖）
│   ├── almanac.js         黄历、宜忌、时辰、节气
│   ├── bazi.js            四柱、五行、大运
│   ├── ziwei.ts           紫微盘面
│   ├── glossary.ts        名词释义库
│   └── constants.*        干支、藏干、十神等常量表
├── pages/                 11 个页面（首页八宫格 + 各功能页）
└── utils/                 图标、缓存等工具
```

## 本地运行

```bash
# 安装依赖
npm install

# 微信小程序：构建 + 监听
npm run dev:weapp

# 生产构建
npm run build:weapp
```

构建产物在 `dist/`。用微信开发者工具导入 `dist/` 目录即可预览；
上传前需在 `project.config.json` 中填入自己的小程序 AppID。

其他端复用同一套代码：

```bash
npm run build:h5     # H5 / 网页版
npm run build:rn     # React Native（需另行配置）
```
